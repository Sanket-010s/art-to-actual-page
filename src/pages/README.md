# Pages

This project uses a single-page layout (`Home`) with section anchors used by `Navbar`.

## Sections (rendered on `/`)

- `Home.jsx` (`#home`) – hero + composes all sections below
- `About.jsx` (`#about`)
- `Skills.jsx` (`#skills`)
- `Achievement.jsx` (`#achievement`)
- `Portfolio.jsx` (`#portfolio`)
- `Contact.jsx` (`#contact`)

## Misc

- `NotFound.jsx` – fallback route (`*`)
- `index.js` – barrel exports for `@/pages`
